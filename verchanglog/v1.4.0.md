# picsw-rust v1.4.0 版本更新日志

**发布日期**: 2026-11-17<br>
**提交数量**: 8 次提交<br>
**版本类型**: 功能新增与体验优化版本

---

## 📋 版本概述

v1.4.0 补齐任务执行过程的细粒度进度与列表操作能力：任务进度弹窗按文档展示已处理图片数进度条，覆盖批量转换、本地上传与图片下载；下载图片与本地上传的文档、图片列表支持一键全部删除；下载图片的「图片 / 成功 / 失败」与本地图片的「图片 / 匹配 / 缺失」改为可点击状态筛选；图片下载新增按文档推送的进度回调，下载目录在应用重启后恢复为空。

---

## ✨ 新增特性

- 任务进度弹窗新增「文档图片进度」区块：每个文档显示文件名、状态、已处理图片数与细进度条；并发度为 3 时多个正在处理的文档同时刷新，排队文档显示等待中，失败文档显示红色进度条与原因。
- 任务进度弹窗总进度条改为全局图片完成度，三项统计保留文档口径并改为「文档 X / Y / 成功 / 失败」。
- 批量转换、本地上传与图片下载均支持文档级图片进度展示；应用重启恢复后台任务后仍可继续查看。
- 下载图片「网络图片文档」列表新增「全部删除」：二次确认后清空文档与识别结果，已下载文件不受影响。
- 下载图片右侧「图片 / 成功 / 失败」改为可点击筛选：默认「图片」为激活态，点击成功或失败只列出对应图片，支持悬停、激活与键盘聚焦样式。
- 图片下载新增文档级进度：命令按文档分组下载并通过 Tauri Channel 逐张推送进度，完成弹窗复用任务进度界面。
- 本地上传「本地图片文档」与「本地图片来源」均新增「全部删除」，共用确认弹窗，任务执行中禁用。
- 本地上传右侧「图片 / 匹配 / 缺失」改为可点击筛选：选择「缺失」时列出文档中未匹配到文件的本地路径并显示缺失标签。

---

## 🐛 Bug 修复

- 修复下载目录在关闭应用后仍保留上次选择路径的问题：移除本地存储读写，启动时清理旧键并初始化为空。
- 修复单文档转换大量图片时总进度条长时间停在 0 的问题：总进度条改为跟随全局图片完成度平滑推进。
- 修复下载图片完成后无法快速定位失败项的问题：新增成功/失败筛选与文档级失败原因展示。

---

## 🚀 性能优化

- 文档进度按图片增量写入单行计数，不重复查询全量文档。
- 下载进度通过 Channel 推送文档索引与计数，前端复用同一任务进度状态，不额外维护轮询接口。
- 下载结果按 URL 映射回原列表，避免依赖返回顺序，减少前端重建开销。

---

## 🔄 重构优化

- 新增 `conversion_task_documents` 表与索引，记录任务内每篇文档的图片总数、已处理数、状态与错误；老数据库启动时自动建表。
- `engine.rs` 在远程转换与本地替换的图片循环中累加文档进度，使用 `MIN(processed_images + 1, total_images)` 防止越界。
- `task_queue.rs` 在任务领取时重置文档进度，文档获得并发许可后标记运行，结束时标记成功/失败并修正进度。
- `get_convert_task` 新增 `documents` 数组，一次轮询同时返回任务与文档进度。
- `download_remote_images` 入参由 URL 数组改为按文档分组的 `documents`，新增 `onProgress` Channel。
- 下载图片与本地图片的状态统计统一使用 `summary-filter` 筛选按钮样式，保持中英文与深浅色一致。

## 🔌 API 变更

- `get_convert_task` 返回值新增 `documents` 数组：`id`、`filename`、`total_images`、`processed_images`、`status`、`error`。
- `download_remote_images` 参数由 `urls` 改为 `documents: [{ filename, urls }]`，并新增 `onProgress` Channel，推送 `document_index`、`filename`、`processed`、`total`、`status`、`error`。
- 前端 `request.ts` 的 `/api/download/images` 路由同步透传 Channel。
- 新增后端用户可见错误「N 张图片下载失败」，已在 `errorText.ts` 补充英文映射。
- 新增中英文词条：任务进度文档标题/状态/计数、下载与本地图片清空与筛选、下载进度标题与提示。

---

## 🗄️ 数据库变更

- 新增 `conversion_task_documents` 表：`task_id`、`filename`、`total_images`、`processed_images`、`status`、`error`、`created_at`、`updated_at`。
- 新增索引 `idx_conversion_task_documents_task_id`。
- 使用 `CREATE TABLE IF NOT EXISTS` 自动建表，无数据迁移；旧任务没有文档进度行时弹窗回退为文档级总进度。

## 🔄 升级说明

v1.3.0 → v1.4.0 无数据迁移要求，安装包覆盖安装即可，本机配置、任务历史、云同步数据与密码均保留。

行为变化说明：

- 任务进度弹窗总进度条改为全局图片完成度；「文档 X / Y」统计仍按已完成文档计数。
- 图片下载完成后默认显示全部图片，可点击「成功 / 失败」筛选；下载目录在应用重启后为空，需要重新选择或输入。
- 本地上传「缺失」筛选展示未匹配的本地路径；清空本地图片后，文档引用会重新标记为缺失。
- 文档失败时进度会修正为图片总数，总进度条仍会到 100%，失败信息以状态与统计数为准。
