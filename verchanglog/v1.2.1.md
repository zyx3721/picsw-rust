## 📋 版本概述

v1.2.1 是云同步自愈与应用内更新的集中强化版本：GitHub 令牌被服务端作废后明确提示「授权已失效」并可一键重新连接，云同步整体暂停不再静默失败；应用内更新从仅 Windows 扩展到三平台六形态（Linux deb/rpm/便携、macOS dmg/便携），下载实时显示进度并按平台自动安装，任一步失败可重试或打开更新包手动处理；同时补齐下载白名单、检查重试、悬浮气泡视口自适应等健壮性与体验优化。

---

## ✨ 新增特性

- GitHub 令牌失效识别与一键重连自愈：令牌被服务端作废（修改 GitHub 密码 / 撤销授权）后，连接行显示红色「授权已失效」徽标与失效说明，云同步整体暂停（自动与手动同步均拦截），任意页签右下角出现可点击的提醒横幅；点击「重新连接 GitHub」重新授权即恢复，本机数据、同步密码与同步快照全程保留。
- 应用内更新扩展至全平台：Linux 支持 deb（pkexec + dpkg）、rpm（pkexec + rpm）提权安装与便携包解压自替换；macOS 支持 dmg 挂载替换 `.app` 与便携包自替换，权限不足或失败自动回退手动安装；Windows 安装版与便携版维持原有链路。
- 更新包下载实时进度：显示百分比与已下载 / 总大小（服务端未返回总长时只显已下载量）。
- 下载 / 安装分离与兜底出口：下载完成后自动安装，失败停留「更新包已就绪」状态，可点「应用更新」重试或「打开更新包」由系统安装器手动处理；便携形态提示手动替换路径。
- 启动检查 24 小时节流与「自动检查更新」开关：启动 8 秒后静默检查（每 24 小时最多一次，可在页内关闭），手动检查不受限。
- 更新信息悬浮展示：「检测到新版本」提示条悬浮即以统一气泡查看该版本的构建信息与更新内容（自动提取前两个章节并清洗 markdown 标记）。
- 「已是最新版」状态化：手动检查无更新时显示绿色胶囊 5 秒自动回落；「上次检查」时间常驻显示。

## 🐛 Bug 修复

- 修复启动时令牌已失效被静默清空凭据、无提示回到未连接的问题：改为保留凭据与连接展示并标记失效态，等待重新授权。
- 修复悬浮气泡在触发元素靠上时超出视口顶部被截断的问题：气泡渲染后按实测高度自适应翻转（上方 → 下方）并在两端贴边钳制。
- 修复安装版目录整体拷走使用时被误判为安装形态的问题：Windows 形态判定改为「卸载程序 + 注册表卸载项」双证，拷贝目录正确按便携处理。
- 修复「已是最新版」仅以 toast 一闪而过、无留痕的问题。

## 🚀 性能与健壮性

- 更新包下载改用专用客户端（连接 15 秒 / 读 30 秒、不限总时长），`.part` 中转防半包，SHA-256 完整性校验保留。
- 更新检查请求增加 1s/2s 退避重试（共 3 次）与完整错误原因链，超时附代理配置指引。
- 更新包与校验清单下载链接增加仓库前缀白名单（纵深防御）。
- 悬浮气泡定位按实测高度决策，短文案提示行为保持不变。
