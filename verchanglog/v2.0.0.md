## 📋 版本概述

v2.0.0 是任务执行与恢复能力的重大升级：批量转换、本地上传与下载图片统一为持久化后台任务，支持退出中断、恢复后继续或取消；图片处理改为逐张容错，新增「部分完成」状态与四项任务统计；下载图片升级为可续传任务，同名文件改为跳过并统计；本地上传新增目录扫描、路径图片与内容哈希去重；三个工作区在切换页签与重启后保留状态，并统一了悬浮提示、默认目标配置与操作提示。

---

## ✨ 新增特性

- 批量转换、本地上传与下载图片统一支持任务中断恢复：应用退出时运行中任务标记为「中断」，重启后可点「继续转换 / 继续上传 / 继续下载」只重试未完成内容，或点对应的「取消转换 / 取消上传 / 取消下载」结束任务；运行中的任务也可随时取消。
- 中断恢复后自动切换到对应功能页签，并保留文档、图片、目标配置与已完成结果；恢复进度弹窗继续展示文档级图片进度。
- 下载图片改为持久化后台任务：逐张记录图片状态与保存路径，支持中断后续传、运行中取消，已完成文档不重复执行。
- 新增图片级失败容忍：单张图片失败时保留原地址与错误并继续处理后续图片，文档状态新增「部分完成」；只有全部图片失败时文档才记为失败。
- 任务进度弹窗新增「成功 / 部分 / 失败」统计，按成功处理的图片数展示进度；问题图片与跳过图片移至文档卡片单独展示，历史记录同步支持部分完成状态与筛选。
- 批量转换识别到图片已属于目标图床时直接跳过上传并保留原地址，文档卡片以独立信息色展示跳过项，与失败项区分。
- 本地上传「选择目录」改用应用内确认弹窗：递归扫描所选目录中的图片，确认后按路径加入；创建任务时由后端读取源文件，不再依赖浏览器原生文件夹上传提示。
- 批量转换与本地上传支持重复文档、重复图片去重：同名文档自动跳过，同一任务内内容完全相同的图片只上传一次；本地上传按内容哈希复用已上传 URL。
- 文档卡片与列表头补充重复数量提示：本地上传显示「文档 N 个 · 本地引用 X 个（Y 个重复）」，下载图片显示「文档 N 个 · 网络图片 X 个（Y 个重复）」。
- 三个任务工作区在切换页签后保持文档、图片、配置与结果；下载图片工作区在重启后保留文档与图片列表，下载目录在无进行中任务时仍重置为空。
- 下载图片目标目录已存在同名文件时直接跳过，不覆盖也不追加序号，并新增「跳过」状态、筛选与数量提示。
- 本地上传目标配置默认选中默认图床，两处目标配置下拉移除「请选择」占位项。
- 全项目悬浮提示统一为 AppTooltip，移除浏览器原生 `title` 提示；下载图片「分析文档」与历史记录「刷新」补充操作完成 toast。

## 🚀 性能优化

- 本地上传按图片内容哈希复用已上传 URL，重复内容不再重复请求图床。
- 下载任务按图片记录状态，续传时只处理未完成图片，已存在文件直接跳过。
- 批量转换跳过已是目标图床的图片，减少无效上传与网络请求。
- 任务进度按图片增量写入文档行，进度弹窗轮询一次即可同时获取任务与文档进度。
- 下载文件改为临时文件原子写入，避免退出或中断时产生半写文件。

## 🔄 重构优化

- `task_queue.rs` 统一三类任务的状态机：任务领取、文档并发、进度累加、成功/部分完成/失败/中断/取消落库集中处理。
- `AppState` 新增取消请求集合，引擎在图片处理循环中按任务检查取消标记，实现运行中协作式取消。
- 下载图片由一次性命令重构为持久化任务，新增 `download_task_images` 逐图记录与原子写入，移除旧的直接下载路径。
- 转换任务新增继续/取消命令与记录兜底恢复；任务载荷补充可继续标记与已完成文档识别。
- `markdown.rs` 图片替换改为容错返回替换数量，支持部分图片失败时继续生成结果。
- 前端抽出统一的 `request()` IPC 路由，新增任务继续/取消、目录扫描与下载任务路由；三个工作区各自维护可持久化状态。
- 引入分任务类型文案（继续转换/继续上传/继续下载等）与统一 AppTooltip、toast 样式。

## 🔌 API 变更

- 新增 Tauri 命令：`resume_convert_task`、`cancel_convert_task`、`scan_image_directory`、`create_download_task`。
- 移除旧的 `download_remote_images` 直接下载命令，下载改为 `create_download_task` 创建任务，再通过 `get_convert_task` 轮询任务、文档与图片状态。
- 前端新增路由：`POST /api/local/scan-images`、`POST /api/download/tasks`、`POST /api/convert/tasks/{id}/resume`、`POST /api/convert/tasks/{id}/cancel`。
- `create_local_convert_task` 的 manifest 支持 `path_images`，图片项支持 `source_path`，可在不传输文件内容的情况下由后端按路径读取。
- `get_convert_task` 返回值新增 `partial`、`resumable`、`documents` 与下载任务的 `images` 数组。
- 任务、文档与图片状态扩展：任务/文档新增 `partial`、`interrupted`、`cancelled`；下载图片新增 `cancelled`、`skipped`。
- 新增任务中断、继续、取消、目录扫描与下载任务相关中文错误，并在 `errorText.ts` 补充英文映射；中英文词条同步新增对应提示。

## 🗄️ 数据库变更

- `conversion_tasks` 新增 `partial INTEGER NOT NULL DEFAULT 0` 列，旧数据库启动时通过 `ensure_column` 自动补齐。
- 新增 `download_task_images` 表：记录任务 ID、文档索引、图片 URL、文件名、保存路径、状态与错误，用于下载续传与逐图结果展示。
- 新增索引 `idx_download_task_images_task_id`。
- 任务与文档状态新增 `partial`、`interrupted`、`cancelled`，下载图片状态新增 `cancelled`、`skipped`；均为增量字段或状态值，无破坏性迁移。
- 图片级替换明细继续使用既有 `conversion_record_details` 表，无需新增表结构。

## 🔄 升级说明

v1.4.0 → v2.0.0 支持安装包覆盖安装，启动时自动补齐 `conversion_tasks.partial` 列并创建 `download_task_images` 表；本机图床配置、转换历史、云同步数据与密码均保留。

行为变化说明：

- 下载图片改为后台任务：点击「下载全部图片」后进入队列，进度弹窗展示文档与图片进度，完成后在列表查看结果。
- 目标目录已存在同名文件时直接跳过，不再生成 `(1)` 之类的序号文件；跳过数量在完成提示与「跳过」筛选中显示。
- 新增「部分完成」状态：单张图片失败不再中断文档，只有全部图片失败才记为失败；任务整体统计包含成功、部分完成与失败。
- 继续或取消任务时，已实际处理完成的文档保持原状态，不会重复执行或变成已取消。
- 本地上传的本地图片文件不会跨重启持久化，已完成上传的文档保留上传状态、匹配统计与结果下载；需要继续处理未完成文档时重新添加图片。
- 若本地上传的临时文件已被清理，任务将不可继续，需要重新添加图片发起新任务。
- 重复文档与重复图片会自动跳过；批量转换中已是目标图床的图片会跳过上传并保留原地址。
- 下载目录仍遵循原有约定：有进行中的下载任务时随任务恢复，无进行中任务时重启后为空。
