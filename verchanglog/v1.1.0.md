## 📋 版本概述

v1.1.0 是图床转站助手桌面版的第二个版本，围绕三条主线迭代：其一，关于页新增检查更新与应用内自动安装能力（Windows 安装版静默安装自动重启、便携版自动解压替换，SHA-256 完整性校验），从此后续版本可在应用内直接升级；其二，云同步体验对照优化，断开连接后冲突状态完整回落、密码冲突恢复由横幅内嵌输入改为独立弹窗、状态徽章显示规则对齐；其三，Windows 安装包与安装向导图标品牌化，安装全程统一项目图标。

---

## ✨ 新增特性

- 新增关于页检查更新与应用内自动安装：启动后自动静默检查 GitHub 最新 Release，已最新提示「当前已是最新版」，检测到新版本时显示绿色「检测到新版本」提示与「更新到 vX.Y.Z」按钮；点击后自动下载更新包（SHA-256 完整性校验），下载完成自动退出并静默安装——安装版静默安装到原路径并自动重启，便携版自动解压替换原文件并重启；非 Windows 平台打开发布页引导手动下载。
- 新增更新运行时识别：自动区分 NSIS 安装版与便携版（按安装目录卸载程序特征判断），分别匹配 Release 安装包与便携压缩包资产。
- 新增 NSIS 安装器品牌化资源：安装包文件图标、安装向导标题栏图标与向导头部图统一替换为项目图标，替代 NSIS 默认图。
- 云同步密码冲突恢复交互升级：由横幅内嵌输入行改为独立弹窗，标题、正文与按钮文案对照保持一致，弹窗采用蓝色主题标题章与聚焦边框，输入框宽度撑满、明文切换由输入框原生能力提供。

---

## 🐛 Bug 修复

- 修复断开 GitHub 连接后冲突横幅残留显示的问题：断开时横幅自动清除，同步状态徽章由「冲突」回落「就绪」。
- 修复同步状态徽章在冲突且从未同步时错误显示云端版本徽章的问题：版本徽章改为仅在上次成功同步后显示，未同步过与已断开时不显示。
- 修复就绪状态徽章无可见背景的问题：补充灰色半椭圆背景，与冲突 / 已拦截 / 待恢复等状态样式统一。
- 修复云端密码弹窗输入框出现双明文切换图标的问题：移除冗余自绘图标，保留输入框原生切换能力。
- 修复检查更新接口调用方式错误导致检查必然失败的问题。

## 🚀 性能优化

- 更新包下载采用流式写入并同步计算 SHA-256，校验失败自动清理残留文件，不占用额外磁盘空间。

## 🔄 升级说明

v1.0.0 → v1.1.0 无数据迁移要求，下载 v1.1.0 安装包直接覆盖安装即可，图床配置、转换历史等本地数据自动保留。

从本版本起，后续新版本可在「关于」页一键检查并自动更新，无需再手动下载安装包；v1.0.0 用户升级到本版本需手动安装一次。
