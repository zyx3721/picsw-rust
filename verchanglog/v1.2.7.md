# picsw-rust v1.2.7 版本更新日志

**发布日期**: 2026-11-16<br>
**提交数量**: 4 次提交<br>
**版本类型**: 问题修正与体验优化版本

---

## 📋 版本概述

v1.2.7 集中完善中英文界面与错误提示：补齐后端错误、任务状态、更新流程与云同步授权等场景的英文映射，修复英文界面中直接显示中文消息、硬编码中文标点与日期格式不一致的问题；同时按图床类型修正转换并发提示，GitHub/Gitee 与单文档任务不再显示「并发度 3」；自动检查更新改为每次启动执行一次。

---

## ✨ 新增特性

- 自动检查更新改为每次启动静默检查一次（仍受「自动检查更新」开关控制），不再按 24 小时间隔节流。
- 中英文覆盖扩展：任务进度与队列状态、窗口标题、配置/转换/下载/更新/云同步错误提示均随界面语言切换。
- 首次启动且没有保存过语言偏好时，按系统语言自动选择中文或英文界面。
- 系统托盘菜单改为中英双语，窗口标题随应用语言切换。

---

## 🐛 Bug 修复

- 修复英文界面任务进度、任务状态与队列提示直接显示中文的问题。
- 修复配置测试成功、删除转换记录成功后直接显示后端中文消息的问题，改用前端词条。
- 修复更新检查、下载、校验与安装失败时英文界面显示中文错误的问题。
- 补齐配置校验、转换任务、下载目录、记录保存、GitHub 授权、系统钥匙串等错误的英文映射。
- 修复 GitHub 超时提示只翻译括号、导致中英文混杂的问题。
- 修复 GitHub/Gitee 目标下进度框错误显示「正在按并发度 3 转换」的问题：这两种图床按仓库分支串行写入，实际上传并发为 1。
- 修复单文档任务仍显示并发度的问题，单文档任务统一显示普通转换提示。
- 修复英文界面出现中文列表分隔符「、」、错误分隔符「；」与中文括号的问题。
- 修复转换记录时间跟随系统语言、而不是应用界面语言的问题。
- 修复切换语言后，已显示的文件/图片错误提示不会重新翻译的问题。
- 修复保存转换结果失败时没有提示、直接调用 Tauri 命令的问题；统一改走 `request` 分发层并补充错误处理。
- 修复中文界面下配置密文错误显示英文 `invalid ciphertext` 的问题。
- 修正 `field.endpoint` 标签、英文星期缩写、版本提示空格、同步时间冒号等文案细节。
- 修正 `index.html` 中过期的页面标题。

## 🔄 重构优化

- `errorText` 固定句式映射由 49 条扩充至 210 条，覆盖配置、转换、下载、同步、更新与上传器错误。
- 新增 `localizeBackendText`，任务状态与错误共用同一套映射，但语义更清晰。
- `write_text_file`、同步令牌、设备码授权等命令统一走 `request.ts` 分发层，业务组件不再直接 `invoke`。
- 日期时间格式化统一由 `formatDateTime` 按应用语言处理。
- 新增仓库型图床判定函数与单元测试，避免后续新增图床时回归。

## 🔄 升级说明

v1.2.6 → v1.2.7 无数据迁移要求，安装包覆盖安装即可，本机配置、任务历史、云同步数据与密码均保留。

行为变化说明：

- 开启「自动检查更新」时，每次启动 8 秒后都会检查一次新版本；关闭开关后不会自动检查。
- 首次启动且未保存语言偏好时，按系统语言选择中文或英文。
- Windows 窗口标题随界面语言切换，托盘菜单显示中英双语。
- GitHub/Gitee 或单文档任务的进度提示不再显示「并发度 3」，改为普通转换提示。
- 后端用户可见错误与任务状态会映射为英文；外部服务返回的原文（如图床接口 JSON、发布说明）保持原样。
