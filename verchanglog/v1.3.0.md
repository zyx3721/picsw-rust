# picsw-rust v1.3.0 版本更新日志

**发布日期**: 2026-11-16<br>
**提交数量**: 11 次提交<br>

---

## 📋 版本概述

v1.3.0 集中解决云同步在真实多设备场景下的可靠性问题，并优化批量转换与历史记录的操作布局：修复图床配置中的脱敏标记被同步到云端、导致合并写回本机失败、版本长期停滞的问题；新增批量转换队列「全部删除」；重排批量转换、本地上传与历史筛选的操作区；历史筛选支持选中后一键清除；统一英文文案与图床术语；macOS 应用内更新自动处理隔离属性与签名，更新后不再需要重复执行 `xattr`。

---

## ✨ 新增特性

- 批量转换队列新增「全部删除」：队列上方显示文档数量与全部删除按钮，二次确认后清空；转换/识别执行中禁用，清空不影响已转换结果与本地文件。
- 批量转换右侧布局调整：目标配置下拉框占满整行，「批量识别」「开始批量转换」移到下方并分别靠左、靠右对齐。
- 本地上传「图片来源」布局调整：「上传图片」「选择目录」移到标题下方，分别靠左、靠右对齐。
- 历史记录筛选区调整：标题与计数独占一行，搜索、状态、源图床、目标图床、时间、刷新、删除整体下移并占满整行；搜索框弹性填充剩余宽度，四个筛选框同步加宽。
- 历史筛选标签改为「状态 / 源图床 / 目标图床 / 时间」，移除「全部…」选项；选中后显示叉叉按钮，点击清除并恢复默认；默认文字为灰色，选中文字为实色。
- 历史记录无匹配提示改为「无匹配记录」/`No matching records`。
- macOS 应用内更新新增 Gatekeeper 处理：dmg 更新先暂存 `.app`，校验/补齐 ad-hoc 签名并移除 `com.apple.quarantine`；替换时使用 `ditto` 保留签名与扩展属性；更新后无需再次执行 `xattr` 命令。

## 🐛 Bug 修复

- 修复云同步应用云端配置失败、版本停留在 v13 的问题：配置中的脱敏标记 `masked: true` 被原样上传并写回 `update_config`，触发 Rust 类型错误；本机与远端配置统一过滤非字符串字段，合并写回前再次清洗。
- 修复云同步状态行只显示「上次成功同步版本」、无法看出云端已有更新的问题：本机落后时显示 `v13 → v16` 并标黄；自动同步失败显示「同步失败」，悬停可查看原因；历史弹窗读取 Gist 实时版本。
- 修复历史记录详情表格出现横向滚动条的问题：移除表格固定 `min-width`，按容器宽度自适应，源/目标地址列各缩 3px。
- 修复「清空队列」「删除图床配置」「GitHub 图片代理」「任务进度」四个弹窗图标与标题纵向排列的问题，统一为图标在左、标题在右、说明在下。
- 修复任务进度提示「关闭窗口不会中断进度」表述不准确的问题：明确最小化到托盘不中断、退出应用会中断当前进度。
- 修复英文界面部分图床相关文案与术语不一致的问题：恢复英文文案优化，并统一使用 `picbed` / `Picbed`；精简关闭行为英文说明，补齐 macOS 更新错误英文映射。
- 修复英文界面历史筛选文案过长导致的截断与按钮竖排问题。

## 🔄 重构优化

- 云同步新增 `sanitizeConfigMap` / `normalizeSyncItem`，本机快照、远端解密、指纹计算、上传载荷与合并写回使用同一套归一化逻辑。
- 云同步历史弹窗改为读取当前 Gist 文件的实时 `meta.version`，不再依赖启动时缓存。
- macOS 更新安装新增 `ditto` 暂存、`codesign` 校验/ad-hoc 签名、`xattr` 隔离清理与目标包后处理；macOS 目录复制由 `cp -R` 改为 `ditto`。
- `errorText` 补充 macOS 更新暂存、ditto、codesign、ad-hoc 签名失败、复制命令等英文映射。
- 历史详情表格移除固定最小宽度，筛选区改为一套可换行的弹性布局。
- 历史筛选与批量转换布局保持中英文共用，不引入语言分支。

## 🔄 升级说明

v1.2.7 → v1.3.0 无数据迁移要求，安装包覆盖安装即可，本机配置、任务历史、云同步数据与密码均保留。

行为变化说明：

- 云同步会过滤配置中的 `masked` 等非字符串标记；完成一次同步后版本会继续推进，不再停在旧版本。
- 本机落后于云端时，状态行版本徽章显示「本机版本 → 云端版本」；自动同步失败会保持「同步失败」状态，直到下次成功同步。
- 历史筛选不再提供「全部…」选项，选中后点击右侧叉叉清除；默认文字为灰色。
- 批量转换队列可一键全部删除，确认弹窗说明不影响已转换结果与本地文件。
- macOS 首次安装仍需执行一次 `sudo xattr -rd com.apple.quarantine "/Applications/PicBed Switcher.app"`；通过应用内「检查更新」安装的新版本已自动处理，无需再次执行。
