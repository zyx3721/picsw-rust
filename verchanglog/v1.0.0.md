## 📋 版本概述

v1.0.0 是图床转站助手桌面版（PicBed Switcher Desktop）的首个正式版本：基于 Tauri 2 构建（Rust 内核 + Vue 3 前端），面向 Markdown 文档的图床地址批量迁移与替换场景，单用户免登录、数据全量本地化、不监听任何网络端口。内置 GitHub 私有 Gist 云同步（端到端加密、三方合并、修订历史恢复）、十类图床上传适配、持久化任务队列与六平台 CI/CD，并提供 Windows / macOS / Linux 各自 amd64 + arm64 共六平台安装包。

---

## ✨ 新增特性

- 新增 Tauri 2 桌面应用外壳，前后端通过 Tauri IPC 通信，不监听任何网络端口。
- 新增十类图床上传适配：GitHub、Gitee、腾讯云 COS、阿里云 OSS、七牛云、百度云 BOS、华为云 OBS、又拍云、MinIO（S3 兼容）、EasyImage 与通用上传接口，S3 兼容存储自实现 SigV4 请求签名。
- 新增 Markdown 图片地址分析与批量转换：自动识别 `![]()` 与 `<img>` 图片及其图床类型，批量上传并替换。
- 新增本地上传替换：识别文档中的本地图片引用（相对路径、绝对路径、`<img>` 标签），按路径与文件名智能匹配后上传替换。
- 新增图片批量下载：上传含网络图片的 Markdown，自动识别全部远程图片地址并批量下载到自定义目录。
- 新增持久化任务队列：任务先落 SQLite 再由后台 worker 消费，任务内多文档并发转换（并发度 3），应用重启后排队任务自动恢复执行。
- 新增转换历史记录：保留最近 50 条记录，支持批量删除、搜索与时间范围筛选，逐图替换明细可查看。
- 新增图床配置管理：增删改查、连接测试、默认配置全局唯一，敏感信息 AES-256-GCM 加密存储、界面脱敏。
- 新增 GitHub 私有 Gist 云同步：同步密码派生密钥（WebCrypto AES-256-GCM + PBKDF2）端到端加密，配置变更 3 秒自动上传与手动同步，三方合并与双向删除传播，收缩护栏拦截，修订历史浏览、预览与两步确认恢复。
- 新增云同步网络与容错体系：GitHub API 自动重试、设备码轮询容错、上次同步状态持久化、密码冲突横幅（云端密码恢复 / 本地覆盖）。
- 新增 GitHub 令牌系统钥匙串存储（无钥匙串环境回退机器绑定加密文件）与 OAuth 设备码授权。
- 新增文件命名格式：支持 `{y}`、`{m}`、`{d}`、`{hash}`、`{random}`、`{rand:N}`、`{timestamp}` 等变量组合。
- 新增关于页：展示应用版本与项目仓库入口。
- 新增系统托盘与关闭确认：托盘左键恢复窗口、右键提供显示窗口与退出菜单；关闭窗口时弹窗三选一（退出应用 / 隐藏到托盘 / 取消）。
- 新增单实例运行：应用已打开时重复启动自动静默跳过。
- 新增六平台 CI/CD 工作流：Windows / macOS / Linux 各自 amd64 + arm64，推送 `v*` 标签自动构建并创建 GitHub Release。

## 🚀 性能优化

- GitHub API 请求内置网络自动重试（3 次递增间隔），弱网环境下同步与授权成功率显著提升。
- 同步加解密运行于 WebView 原生 WebCrypto（BoringSSL，SHA-NI 硬件加速），修订预览解密毫秒级响应。

## 🔄 升级说明

v1.0.0 为首个正式版本，无历史版本升级迁移要求。

安装对应平台安装包即可使用；业务数据自动保存在本机应用数据目录（Windows 为 `%APPDATA%\com.picsw.desktop\picbed.db`），备份时关闭应用后拷贝该目录下的 `picbed.db` 即可。云同步的 GitHub 令牌存于系统钥匙串、同步进度快照存于 WebView 本地存储，不随 `picbed.db` 备份迁移。
