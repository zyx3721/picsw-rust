## 📋 版本概述

v1.2.0 是云同步自动化与安全护栏的集中强化版本：同步密码支持记住并在启动时自动解锁，启动与断开重连后都会自动对齐一次云端；空库与收缩两条安全护栏补齐并重制为统一的红色警示样式；检查更新改走后端请求并新增发布页回退通道；关于页卡片化新增问题反馈与发布说明入口；同时修复安装器头部图拉伸变形与检查更新 403 等问题。

---

## ✨ 新增特性

- 云同步支持记住同步密码：解锁或设置成功后自动存入本机密钥库（系统钥匙串优先，无钥匙串环境回退机器绑定加密文件），下次启动自动解锁；同步面板新增「锁定」按钮，一键清除内存与本机记住的密码。
- 启动自动对齐：应用启动后连接与解锁就绪时自动执行一次云端同步，无论自动同步开关是否勾选（失败静默，不阻塞启动）。
- 重连自动对齐：断开 GitHub 后重新连接，只要同步密码处于已解锁状态即自动同步一次，与自动同步开关无关。
- 「发现云端备份」空库横幅：本机没有图床配置而云端有备份时弹出红色警示卡片，可选择「恢复云端数据」或「推送本机数据」处理。
- 远端未变路径补齐收缩护栏：单机大量删减配置后同步同样触发拦截，与合并路径口径一致。
- 关于页卡片化：新增「反馈问题」与「更新内容」卡片，一键直达 Issues 与 Releases 页面；版本、GitHub、反馈、更新四张卡片均配图标章。
- 删除图床配置确认弹窗支持回车键快捷确认。

---

## 🐛 Bug 修复

- 修复安装向导头部图标被横向拉伸变形的问题：NSIS 头部位图按原生 150×57 规格重制，图标比例恢复方正。
- 修复检查更新报「GitHub 接口响应异常（403）」的问题：版本检查改由 Rust 端统一 User-Agent 请求官方接口，异常时自动回退发布页 302 跳转解析版本号。
- 修复云同步横幅内容居中显示的问题：横幅类名与空状态样式冲突，已隔离命名。

## 🎨 界面优化

- 收缩护栏横幅重制：红色警示卡片样式，标题「同步被拦截：本次推送会删除过多数据」，正文展示配置条数变化明细；「强制推送」按钮调整为红色。
- 恢复预览中配置缩减时数字与「（将减少 N 条）」提示以红色标注。
- 操作提示文案统一：「恢复云端数据」「强制推送」按钮，「已拉取云端数据」「已恢复云端数据」「已推送本机数据」「已强制推送本地数据」「同步密码已配置」等提示。
