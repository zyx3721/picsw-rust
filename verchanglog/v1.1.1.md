# picsw-rust v1.1.1 版本更新日志

---

## 📋 版本概述

v1.1.1 是针对 v1.1.0 引入的应用内检查更新功能的集中修正版本：修复 Windows 安装包资产名匹配失败与校验和清单解析失败两类导致自动更新无法完成的问题，更新过程不再弹出终端窗口，更新完成后自动清理临时下载文件与说明文件，同时将启动自动检查的延迟缩短到 1 秒，并把安装向导头部图调整为正方形白底图标。

---

## 🐛 Bug 修复

- 修复 Windows 安装版点击「更新到 vX.Y.Z」后跳转浏览器而非下载的问题：安装包 Release 资产名使用点号分隔，资产匹配规则与之对齐。
- 修复便携版更新时「Failed to fetch」报错的问题：校验和清单改由 Rust 端获取与解析，避开 WebView 对 GitHub 下载链路重定向的跨域拦截。
- 修复校验和清单解析失败提示「校验信息中未找到更新包」的问题：兼容 sha256sum 输出的 `*` 二进制模式前缀，以及安装包名在清单与资产间的空格 / 点号分隔差异。
- 修复便携版更新过程中弹出终端窗口的问题：替换脚本以无窗口模式启动。
- 修复更新残留文件未清理的问题：便携版替换后自动删除随包的 README.txt 与临时下载目录；安装版由新版本首次启动时清空临时下载目录兜底。

---

## 🚀 性能优化

- 启动自动检查更新的延迟由 4 秒缩短为 1 秒，更快呈现新版本提示。

---

## 🎨 界面优化

- 安装向导头部图由横向长条调整为 57×57 正方形白底图标，安装全程视觉统一。

---

## 📄 文档更新

- README 中文 / 英文双语明确应用内自动更新仅支持 Windows 平台。

---

## 🔄 升级说明

v1.1.0 → v1.1.1 无数据迁移要求。v1.1.0 用户可直接在「关于」页点击「检查更新」通过应用内更新升级；更早版本用户下载 v1.1.1 安装包覆盖安装即可，本地数据自动保留。
